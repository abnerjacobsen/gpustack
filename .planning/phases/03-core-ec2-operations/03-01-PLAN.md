    Create aws_ami_mapping.py module that maps AWS regions to Deep Learning AMIs for GPU instance types.

    **Deep Learning AMI Strategy:**
    AWS Deep Learning AMIs (DLAMI) provide pre-installed NVIDIA drivers, CUDA, and container toolkit.
    Use the latest DLAMI for Ubuntu 22.04 (GPU-optimized) for each supported region.

    **AMI Mapping Requirements:**
    - Map regions to AMI IDs for both x86_64 and arm64 architectures
    - Support regions: us-east-1, us-east-2, us-west-1, us-west-2, eu-west-1, eu-central-1, ap-southeast-1
    - GPU instance families: p3 (V100), p4d (A100), g4dn (T4), g5 (A10G) - all x86_64
    
    **Implementation approach:**
    - Use AWS Systems Manager Parameter Store to get latest DLAMI dynamically:
      - Parameter path: /aws/service/ec2/ami-amazon-linux-latest/amzn2-ami-hvm-x86_64-gp2 (example)
    - For DLAMI specifically, use: /aws/service/marketplace/prod-a5y7p7mojcsus/latest
    - Or create a lookup that queries EC2 describe_images with owner=amazon and name filters
    - Better approach for MVP: Static mapping with documented update process

    Replace the NotImplementedError stub with full create_instance() implementation.

    **Method signature:** Already defined in abstract.py
    ```python
    async def create_instance(self, instance: CloudInstanceCreate) -> Optional[str]
    ```

    **Implementation steps:**

    1. **Prepare instance parameters:**
       - Get AMI ID: Use aws_ami_mapping.get_ami_for_region(instance.region)
       - Instance type: instance.type (e.g., "p3.2xlarge", "g4dn.xlarge")
       - Key name: instance.ssh_key_id (AWS key pair name from create_ssh_key)
       - User data: instance.user_data (cloud-init script)

    2. **Build network configuration (from AWSConfig):**
       - If config.subnet_id: Use SubnetId in NetworkInterfaces
       - If config.security_group_id: Use SecurityGroupIds
       - If config.vpc_id: Only needed if creating new resources (use default for now)

    3. **Build run_instances request:**
       ```python
       run_args = {
           "ImageId": ami_id,
           "InstanceType": instance.type,
           "KeyName": instance.ssh_key_id,
           "MinCount": 1,
           "MaxCount": 1,
           "UserData": instance.user_data,  # base64 encoded automatically by boto3
           "TagSpecifications": [
               {
                   "ResourceType": "instance",
                   "Tags": [
                       {"Key": "Name", "Value": instance.name},
                       {"Key": "ManagedBy", "Value": "GPUStack"},
                       {"Key": "GPUStackWorker", "Value": "true"},
                   ] + [{"Key": k, "Value": v} for k, v in (instance.labels or {}).items()]
               }
           ]
       }
       
       # Add network configuration if subnet specified
       if self.config and self.config.subnet_id:
           run_args["NetworkInterfaces"] = [{
               "SubnetId": self.config.subnet_id,
               "DeviceIndex": 0,
               "AssociatePublicIpAddress": True,
               "Groups": [self.config.security_group_id] if self.config.security_group_id else []
           }]
       elif self.config and self.config.security_group_id:
           run_args["SecurityGroupIds"] = [self.config.security_group_id]
       ```

    4. **Call EC2 run_instances:**
       ```python
       async with self._get_client() as client:
           response = await client.run_instances(**run_args)
           instance_id = response["Instances"][0]["InstanceId"]
           logger.info(f"Created EC2 instance {instance_id} of type {instance.type}")
           return instance_id
       ```

    5. **Error handling:**
       - Use existing _handle_aws_error() for ClientError
       - Handle specific cases: 
         - InvalidAMIID.NotFound: Clear error about AMI not available
         - InsufficientInstanceCapacity: GPU instance not available in region/AZ
         - VcpuLimitExceeded: Service quota exceeded

    6. **Update imports in aws.py:**
